- 추가됨: 1층 문틀·창틀, 3층 외벽/코어벽/계단 난간/지붕, 3층 실내 칸막이,

3층 실내 (루트 4막용, 2026-09-01)
- 복도: y -1.00 ~ 2.20 (2층 복도와 같은 선 → 3층 칸막이가 2층 벽 위에 섭니다)
- 송출 관제실 12.0 x 4.8m / 기계실 6.0 x 4.8m / 창고 A 12.0 x 6.0m / 창고 B 6.0 x 6.0m
- 전자문(키패드) 개구부: 복도 북쪽 벽, x = -4.00, 폭 1.60m, 높이 2.40m
- 완강기 탈출창: 서쪽 외벽 x = -10.00, y = 4.50, 폭 1.60m, 하단 0.90m, 높이 1.60m
  (다른 창은 하단 1.10m라 못 넘어갑니다. 이 창만 낮게 뚫었습니다)
- Play Mode의 Lab Blockout > Check 3F Act 4 route 로 동선 전체를 다시 걸어볼 수 있습니다.

Scenes 폴더의 LabHorror_Blockout_Step7_3F_Floor 씬을 여세요.
Models 폴더의 FBX는 원본 구조 모델입니다.
Prefabs 폴더의 프리팹에는 벽/바닥 충돌과 계단용 부드러운 충돌판이 설정되어 있습니다.

3층 외피 (2026-09-01 추가)
- 외벽: 2층과 같은 외곽선(X -12…10, Z -7…7)과 같은 창 리듬. 창 하단 1.10m, 높이 1.20m.
- 벽 높이: 바닥 6.40m ~ 상단 9.60m. 지붕 슬래브는 9.40~9.60m.
- 코어: X=-8 구획벽, 계단실 벽(문 개구부 포함), 엘리베이터 샤프트 4면 벽.
- 계단 개구부 난간 4개(높이 1.10m). 남쪽 난간은 계단이 올라오는 폭만 비워 두었습니다.
  이전 상태에서는 이 남쪽 가장자리에 폭 1.76m 추락 구멍이 있었습니다.
- 3층 벽·지붕 39개 메시 전부에 BoxCollider와 Static 플래그를 넣었습니다.

치수 감사 및 모서리 수정 (2026-09-01)
- Tools/audit_blockout_geometry.py 로 전체 블록아웃을 측정했습니다(읽기 전용).
- 이미 정상이던 것: 벽 두께 전부 0.220m, 슬래브 전부 0.200m, 같은 벽면 세그먼트 사이 틈 0,
  바닥 슬래브 사이 틈 0, 벽 하단이 뜬 것 0.
- 발견된 결함: 층마다 네 모서리에 110 x 110mm 슬롯이 층높이 3.2m 전체를 관통 (총 12곳).
  서/동 벽이 남/북 벽의 중심선까지만 가고 바깥면까지 가지 않아서 생겼습니다.
- Blender 소스 스크립트(step2/step5/step9)를 고치고 Step2부터 전체 체인을 다시 돌렸습니다.
  Unity에서 고치면 다음 재익스포트에 지워지기 때문입니다.
- 재익스포트로 길이가 바뀐 벽 11개의 콜라이더를 다시 맞췄습니다.
  계단 램프 콜라이더 4개는 디딤코 평면 보정(center.z = -0.1)이라 손대지 않았습니다.
- 남은 것(결함 아님): 모서리·T자 이음의 0.11m 겹침 49건은 의도된 봉합입니다.
  베벨 모따기(12mm 99개 등)는 이음매가 가는 홈으로 보이는데, 없애길 원하시면 말씀해 주세요.

이동 테스트
- Play 실행 후 Game 화면을 클릭하면 시점과 이동을 조작할 수 있습니다.
- WASD 이동 / 마우스 시점 / Esc 커서 해제 / R 정문 안쪽 시작 위치로 복귀
- 눈높이 1.65m, 몸 높이 1.8m, 이동 속도 3m/s입니다.
- 달리기·점프·숨죽이기·손전등·소리는 이번 테스트에 포함하지 않았습니다.
- 기존 Overview Camera는 삭제하지 않고 비활성화했습니다.
- 정문 밖 지상에는 아직 추락 방지 구조가 없습니다.
