## A. 먼저 고쳐야 할 것 — 방송실 입구 (지금 들어갈 수 없음)

`won`에서 고쳤던 게 병합에 안 넘어와서 3층 루트가 막혀 있습니다. 이거 셋을 먼저 해주세요.

### A-1. VARCO 문 삭제
```
VARCO_Placed_Props / VARCO_3F / PROP_3F_Broadcast_SlidingDoor
```
개구부(x 4.8~7.2)에 콜라이더째로 박혀 있습니다. 블록아웃 문이 열려도 이게 막습니다. **삭제.**

### A-2. VARCO 키패드 삭제
```
VARCO_Placed_Props / VARCO_3F / PROP_3F_Broadcast_Keypad
```
제가 만든 `PROPS_3F_Broadcast / PROP_3F_Keypad_*` 와 같은 자리에 겹쳐 있습니다. **VARCO 쪽만 삭제.**

### A-3. 방송실 문 잠금 해제
```
Doors_And_Windows / Doors / AUTO_DOORS / DOOR_3F_CORRIDOR_NORTH_HEADER_01
```
Inspector의 **Sliding Door** 컴포넌트에서

| 필드 | 지금 | 바꿀 값 |
|---|---|---|
| Access | `Sealed` | **`Unlocked`** |
| Label | `제한 구역` | **`방송 통제실`** |

16번 비트에서 열고 17번에서 닫아야 하므로 여닫이가 둘 다 필요합니다.
나머지 3층 문(`NORTH_HEADER_02`, `SOUTH_HEADER_01/02`, `ELEVATOR_SHAFT`)은 `Sealed` 그대로 두세요 — 안 쓰는 방입니다.

> **주의:** 문이 잘 열리는지 확인은 **반드시 Play 모드에서** 하세요. 에디트 모드에서 열어보면 문짝이 원점으로 날아갑니다.

## 참고 — 왜 수동인가

스크립트로 프리팹 안 오브젝트를 옮기면 nested prefab 구조가 깨집니다. 실제로 두 번 당했습니다.

- 문짝 2개가 (0,0,0)으로 날아감 — `SetOpenImmediate`를 에디트 모드에서 호출 (shut 위치는 `Awake`에서만 기록됨)
- 3층 방송실 279개가 통째로 19 m 어긋남 — 프리팹 루트의 X 270° 회전을 홀더가 상쇄하지 않음

팀 `CLAUDE.md` 4번 항목과 같은 이야기입니다.
