# Part 0 — 룩 확립과 퀄리티 기준

맵·오브젝트 레인의 **첫 작업**. 구역별 작업(Part A~E) 전부가 여기서 정한 것을 적용한다.
전체 계획은 [Route_And_Build_Parts.md](Route_And_Build_Parts.md).

## 왜 이게 먼저인가

"허술한 플래시게임처럼 보인다"의 원인은 지오메트리가 아니다. 지오메트리는 이미 321개
렌더러에 벽·바닥·계단·개구부가 다 서 있다. 원인은 **룩이 통째로 비어 있다는 것**이다.

측정한 현재 상태:

| 항목 | 현재 | 공포게임에서 필요한 것 |
|---|---|---|
| 라이트 | **2개** (Directional 1, 책상등 1) | 구역마다 국소 광원, 대부분 꺼진 상태 |
| 그림자 | **둘 다 `shadows = None`** | 그림자가 공포의 절반이다 |
| 포스트프로세싱 Volume | **0개** | 비네트, 필름그레인, 색보정, 블룸 |
| 리플렉션 프로브 | **0개** | 젖은 바닥·금속이 검게 죽는다 |
| 베이크된 라이트맵 | **0개** | 전부 실시간 = 어둠이 밋밋하다 |
| 안개 | **꺼짐** | 거리감·시야 제한 = 공포의 도구 |
| 머티리얼 | 27개, **전부 단색 무텍스처** | 콘크리트·타일·금속·녹·페인트 |

라이트를 하나도 안 켜고 그림자를 전부 끈 상태에서는, 벽을 아무리 정교하게 세워도
회색 상자로 보인다. **그림자 켜기 하나가 지금 할 수 있는 가장 큰 퀄리티 변화다.**

## 하는 일

### 0-1. 레퍼런스 룸 하나를 최종 퀄리티로
전체에 손대기 전에 **방 하나만** 끝까지 만든다. 여기서 팔레트·머티리얼·라이팅·
포스트프로세싱을 다 정하고, 나머지 구역은 그걸 복제한다.
이걸 안 하면 1F를 다 꾸민 뒤에 룩이 바뀌어서 처음부터 다시 하게 된다.

**추천: 경비실** (월드 x 7.5…15, z −10.5…−3)
- 5×5 m로 작아서 반복 수정이 빠르다
- 책상(`PROP_1F_Guard_WoodenOfficeDesk`)과 책상등, 손전등이 이미 있다
- 루트 초반에 플레이어가 실제로 들어가는 방이다

### 0-2. 머티리얼 세트
27개 단색 머티리얼을 실제 재질로 교체한다. 최소 세트:
`콘크리트(벽/바닥)`, `타일`, `도장 금속`, `녹슨 금속`, `유리`, `고무/몰딩`,
`젖은 바닥`, `얼룩/그을음`
- 텍스처 조달은 0-4 참조
- 머티리얼 이름은 `M_` 접두사 규약을 따른다

### 0-3. 라이팅 규칙
공포게임 라이팅은 "밝기"가 아니라 **어디를 안 비출지**를 정하는 작업이다.
- Directional: 그림자 **켜기**, 강도는 지금의 1.15보다 훨씬 낮게 (달빛 수준)
- 구역마다 국소 광원: 비상등, 깜빡이는 형광등, 책상등 — 대부분 꺼져 있거나 고장
- 손전등이 유일한 안정 광원이 되게 (`BlockoutWalkPlayer`에 이미 있음, 단 `shadows = None` → 켜야 함)
- 전력 복구(루트 15) 전후로 **조명이 통째로 바뀌는** 연출이 루트에 있다 → 조명을 두 세트로 설계
- 정적 지오메트리는 라이트맵 베이크, 손전등만 실시간

### 0-4. 포스트프로세싱 + 안개
- Global Volume 신설: 비네트, 필름그레인, 색보정(차갑고 채도 낮게), 블룸(약하게),
  모션블러는 끄거나 아주 약하게(1인칭 공포에서 멀미 유발)
- 안개: 지수형, 시야 10~15 m 정도로 제한 → 넓은 로비가 무한히 보이지 않게 하고
  동시에 드로우콜도 줄인다

### 0-5. 손상 표현 규칙 〔공격받은 건물〕

현재 건물은 **너무 깨끗하다**. 모든 벽이 완전한 직육면체고, 금 하나 없고, 바닥에
아무것도 안 떨어져 있다. 연구소가 습격당하고 붕괴한 설정인데 신축 건물처럼 보인다.
입구 붕괴 잔해(`MAIN_ENTRANCE_COLLAPSE_SEQUENCE`, 조각 40 + 잔해 62)만이 유일한 예외고,
이건 오히려 **나머지가 얼마나 깨끗한지를 드러낸다**.

손상은 아무 데나 흩뿌리는 게 아니라 **읽히는 규칙**이 있어야 한다. 레퍼런스 룸에서
아래 층위를 다 만들어보고, 각 구역은 이 어휘만 조합한다.

| 층위 | 내용 | 만드는 곳 |
|---|---|---|
| **구조 손상** | 벽에 뚫린 구멍, 무너진 천장, 기운 기둥, 갈라진 바닥 | Blender (지오메트리) |
| **비구조 잔해** | 떨어진 천장 패널, 무너진 선반, 뒤집힌 가구, 콘크리트 파편 | Blender + Unity 배치 |
| **표면** | 균열, 그을음, 물 얼룩, 벗겨진 페인트, 녹 | 머티리얼 / 데칼 |
| **흔적** | 핏자국, 긁힌 자국, 손자국, 끌린 자국 | 데칼 |
| **매달린 것** | 늘어진 전선, 부서진 조명, 열린 덕트 | Blender 프롭 |

**중요한 제약** — 손상은 통행을 막을 수도 있고 막지 않을 수도 있는데, 그 차이가
루트를 좌우한다. 그래서 손상 프롭은 두 종류로 나눠 이름 짓는다:
- `DMG_*` — 장식. 콜라이더 없거나 벽에 붙어 있어 통행에 영향 없음
- `BLOCK_*` — 통행 차단이 **의도된** 것. 루트 4의 "나머지는 다 무너져있음",
  루트 5의 배전반실 막는 장애물이 여기 해당

이 구분을 안 지키면 나중에 플레이어가 못 지나가는 곳이 생기고, 왜 막혔는지 추적이 안 된다.
플레이모드 워크 체크 5종이 이걸 잡아주므로 **손상 배치 후 반드시 재실행**한다.

### 0-6. 텍스처·에셋 조달
- 이미 있는 것: `SciFi Warehouse Kit` (모델·텍스처·SFX 포함) — **먼저 여기서 찾는다**
- VARCO 프롭 10종은 배치돼 있으나 머티리얼은 단색 — 텍스처 입히기 대상
- 모자란 것만 생성하거나 외부 조달

## 완료 조건

경비실 안에 서서 스크린샷을 찍었을 때, **블록아웃이 아니라 게임 장면으로 보인다.**
구체적으로:
- 광원이 2개 이상이고 그중 하나 이상이 그림자를 드리운다
- 벽·바닥·책상이 서로 다른 재질로 보인다
- 손전등을 끄면 실제로 어둡고, 켜면 그림자가 움직인다
- 포스트프로세싱이 적용돼 있다
- **습격당한 방으로 보인다** — 0-5의 다섯 층위가 전부 한 번씩은 등장한다
- 워크 체크 5종이 여전히 통과한다 (손상이 통행을 의도치 않게 막지 않았다)

이 스크린샷이 나머지 구역의 기준선이 된다.

## 안 하는 것

- 다른 구역 꾸미기 — 0-1이 끝나야 시작
- 프롭 신규 모델링 — Part A~D에서 구역별로
- 게임플레이 로직 — 팀의 다른 파트
