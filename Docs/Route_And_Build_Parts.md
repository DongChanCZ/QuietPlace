## 3. 빌드 파트 (우선순위 순)

### 작업 규칙 (사용자 지정, 2026-09-02)

> **한 번에 하나씩, 완성도 높게.** 여러 개를 동시에 처리하면 퀄리티가 떨어진다.

파트 안에서도 항목 단위로 쪼개서 하나를 끝내고 다음으로 넘어간다.
시각 작업이므로 **항목마다 스크린샷으로 확인**하고, 넘어가기 전에 커밋한다.
"거의 다 됐다"는 상태를 여러 개 쌓아두지 않는다.

각 파트는 재실행 가능한 체크를 하나 남긴다.

> **괴물과 괴물 소리는 마지막(Part 7)에 한 번에 만든다** — 사용자 결정, 2026-09-02.
> 가장 무거운 시스템이고, 나머지는 괴물 없이도 전부 만들고 검증할 수 있다.
>
> **대신 각 파트는 괴물이 나중에 소비할 훅만 남긴다.** 이걸 지키지 않으면 Part 7에서
> 앞 파트를 전부 다시 열어야 한다. 훅은 두 가지뿐이다:
> - `HidingSpot.IsHidden` — 숨은 동안 참. Part 1에서 만들고 Part 7까지 아무도 안 읽는다
> - `NoiseEvent(위치, 크기)` — 소음을 내는 행동이 발행. 던진 퓨즈, 밟은 유리파편,
>   떨어뜨린 모듈, 부서지는 장애물. Part 7 전까지 **구독자가 없다**
>
> 구독자 없는 이벤트를 미리 만드는 건 투기적 추상화가 아니다 — 루트에 소비처가
> 이미 7군데 적혀 있다.

### 레인 구분 (팀플)

내 담당은 **맵과 오브젝트**다. 게임플레이 로직은 팀의 다른 사람 몫이다.

| 내 파트 | 팀의 다른 파트 |
|---|---|
| 지오메트리, 방 배치, 손상 표현 | 상호작용, UI |
| 머티리얼, 라이팅, 포스트프로세싱 | 숨기 로직, 미니게임 |
| 프롭 모델링·배치·콜라이더 | 사운드 시스템, 괴물 AI |

**인계 규약** — 프롭은 내가 여기까지 마감해서 넘긴다. 그래야 로직 담당이
오브젝트를 옮기거나 다시 만들 필요가 없다:
1. 루트에 쓰이는 이름 (`ITEM_2F_TransformerModule` 처럼 층·용도가 이름에 들어감)
2. 콜라이더가 붙어 있고 크기가 메시와 맞음
3. 상호작용 지점이 필요하면 자식 빈 오브젝트로 앵커를 남김
   (숨는 위치, 손에 드는 위치, 설치되는 위치)
4. 통행 차단 여부가 이름으로 구분됨 (`DMG_` 장식 / `BLOCK_` 차단)

### Part 0 — 룩 확립과 손상 표현 〔최우선〕
상세: [Part0_Look_And_Quality.md](Part0_Look_And_Quality.md)

측정 결과 "허술해 보이는" 원인은 지오메트리가 아니라 룩이 통째로 비어 있다는 것이다:
**라이트 2개(둘 다 그림자 OFF), 포스트프로세싱 0, 리플렉션 프로브 0, 라이트맵 0,
안개 OFF, 머티리얼 27개 전부 무텍스처 단색.** 그리고 습격당한 건물인데 벽에 금 하나 없다.

경비실 하나를 최종 퀄리티로 끝내서 팔레트·머티리얼·라이팅·손상 어휘를 확정한다.
**이걸 먼저 안 하면 구역을 다 꾸민 뒤 룩이 바뀌어 전부 다시 하게 된다.**

### Part A — 1F 튜토리얼 구역 (루트 1, 2, 4)
- 로비가 19.5 × 21 m로 **완전히 비어 있음** → 루트 4의 "나머지는 다 무너져있음"을
  실제 붕괴 지오메트리로 만들어 동선을 좁힌다 (`BLOCK_*`)
- **반짝이는 테이블 배치** — 모델은 있는데 씬에 없음
- 지도 프롭, 경비실 마감

### Part B — 2F 전력 구역 (루트 5~14) 〔가장 큰 작업〕
**2F 방 구성이 루트와 전혀 안 맞는다.** 현재 방 이름은 도면 없이 지어낸 것:
`OFFICE / MEETING / SAMPLE / CHASE CORRIDOR / CABINET MEMO / RECORDS / BREAK ROOM`
루트가 요구하는 건 **발전소실 / 창고 / 배전반실 / 복도**다. 복도만 맞는다.

→ `Tools/create_step5_second_floor_walls.py`를 Blender에서 다시 짜서 방을 재구성한다.
이미 배치된 2F 프롭 5종(파란선반·변압기모듈·캐비닛·장애물·긴의자)의 위치를
새 방 배치에 맞춰 다시 잡아야 한다.
- 발전소실: 빨간 경고등, 안전수칙 메모판
- 창고: 파란선반 + 변압기모듈
- 배전반실: 배전반, 진입을 막는 장애물
- 복도: 유리파편, 캐비닛, 긴의자, 퓨즈

### Part C — 3F 방송 구역 (루트 16, 18)
`BROADCAST CONTROL` 방은 이미 있고 전자문·키패드·방송콘솔도 배치됨.
추가할 것: 확성기, 컴퓨터 화면, USB, 방송실 손상 표현.

### Part D — B1 엔딩 구역 (루트 21)
B1 두 방은 지어져 있음. **깨진 알** 프롭과 엔딩 컷 연출용 배치.
봉쇄문 너머는 계속 미건축 — 엔딩 카메라에 잡히는 만큼만.

### Part E — 접근 통제 마감
문 119개는 이미 solid라 "막기"는 공짜다. 열리는 문만 골라 카드키 대상으로 표시하고,
나머지는 잠긴 것으로 보이게 마감한다(막힌 이유가 보여야 한다 — 잔해, 봉인, 경고 테이프).

### Part F — 괴물 + 괴물 사운드 (루트 3, 8, 10, 13, 17, 19) 〔마지막〕
**사용자 결정, 2026-09-02: 괴물과 괴물 소리는 마지막에.**
가장 무거운 시스템이고, 나머지는 괴물 없이도 전부 만들고 검증할 수 있다.
모델·애니메이션은 내 파트, AI는 팀 파트일 가능성이 높다.

**대신 앞 파트가 훅만 남긴다.** 안 그러면 여기서 앞 파트를 전부 다시 열어야 한다:
- `HidingSpot.IsHidden` — 숨은 동안 참
- `NoiseEvent(위치, 크기)` — 던진 퓨즈, 밟은 유리파편, 떨어뜨린 모듈, 부서지는 장애물
- 괴물 순찰 경로가 지나갈 공간을 막아두지 말 것 (`BLOCK_*` 배치할 때 유의)

구독자 없는 이벤트를 미리 만드는 건 투기적 추상화가 아니다 — 루트에 소비처가
이미 7군데 적혀 있다.
