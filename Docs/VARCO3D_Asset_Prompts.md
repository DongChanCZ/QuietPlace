# VARCO 3D 오브젝트 생성 명령어

## 공통 제작 규칙

- 한 번에 오브젝트 하나만 생성한다.
- 정면보다 형태가 잘 보이는 3/4 시점으로 생성한다.
- 배경은 단색 중성 회색, 그림자는 약하게 설정한다.
- 사람, 방, 벽, 바닥, 글자, 로고, 떠 있는 부품은 제외한다.
- 실제 크기와 물리적으로 가능한 구조를 명시한다.
- 이미지 확인 후 통과한 결과만 PBR 3D로 변환한다.
